# Requisitos

- Inventariar propriedades existentes antes de criar; preferir propriedade de domínio lafmat.com.
- Usar conta definida pelo responsável; conceder acessos por convite, sem compartilhar senhas.
- Verificar DNS TXT preservando os registros atuais de web e correio.
- Obter exportações de desempenho/indexação, sitemaps, ações manuais e segurança disponíveis.
- Não usar Mudança de endereço para mera troca de hospedagem, caminhos ou www no mesmo domínio.

Fora de escopo: trocar domínio/hospedagem, campanhas pagas e alterações editoriais não solicitadas.
