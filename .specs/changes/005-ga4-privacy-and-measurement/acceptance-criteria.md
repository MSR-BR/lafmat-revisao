# Critérios de aceite

- [ ] Fluxo web correto recebe evento de teste sem PII e com uma única contagem.
- [ ] Consentimento permite recusar/rever; não há coleta contrária à configuração escolhida.
- [ ] Eventos distinguem clique externo de reprodução e clique mailto de envio.
- [ ] Filtros internos inicialmente testados antes de exclusão irreversível de dados.
