# Requisitos

- Submeter sitemap final no Search Console e inspecionar home e amostras representativas de cada idioma/tipo de página.
- Distinguir teste ao vivo, solicitação de indexação e indexação efetiva.
- Solicitar indexação das páginas prioritárias dentro das quotas; não submeter tudo repetidamente.
- Vincular Search Console ao fluxo GA4 correto com permissões apropriadas.
- Não usar Change of Address para hospedagem/caminhos/www no mesmo domínio e não usar Indexing API para páginas não elegíveis.

Fora de escopo: trocar domínio/hospedagem, campanhas pagas e alterações editoriais não solicitadas.
